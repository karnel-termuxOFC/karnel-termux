# Turbopack

Incremental bundler and build system optimized for JavaScript and TypeScript

**Package:** turbopack  
**Author:** israel marques  
**Repository:** https://github.com/karnel-termuxOFC/karnel-termux  
**Type:** Node.js global module (npm)  
**License:** MIT

## Description

Turbopack is the bundler that ships with Next.js. It handles TypeScript, JSX and CSS with an incremental cache, so rebuilds stay fast as a project grows.

## Dependencies

- Node.js LTS (nodejs-lts)

## Install

```bash
karnel install npm --turbopack
```

## Uninstall

```bash
karnel uninstall npm --turbopack
```

## Update

```bash
karnel update npm --turbopack
```

## Notes

- Run through Next.js: `next dev --turbo` (or `next-turbopack dev`)
- Installed as a global npm package
